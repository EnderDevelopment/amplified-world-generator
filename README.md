# Amplified World Generator

Amplify your Minecraft Bedrock world generation like Java Edition.

## Features

- Amplified world generation similar to Java Edition
- Configurable amplification factor for customization

## Requirements

- Minecraft Bedrock Edition
- Forge Mod Loader

## Installation

1. Download the mod from the releases page.
2. Place the mod file in your Minecraft Bedrock mods folder.
3. Launch Minecraft Bedrock and enable the mod in the mod settings.

## Usage

Once installed, the mod will automatically amplify the world generation. You can configure the amplification factor in the mod settings.

## Configuration

The amplification factor can be configured in the mod settings. The default value is 2.0.
